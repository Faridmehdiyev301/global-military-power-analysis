# Global Military Power Analysis

Multi-page Power BI dashboard comparing military strength across countries — covering air, land, naval, manpower, energy, and financial dimensions.

## Overview
This project analyzes global military capability data across multiple countries, broken down into six dashboard pages covering different aspects of military power: air forces, land forces, naval forces, manpower, financial resources, and energy.

## Data Source
Data was collected via Python (web scraping) from a public military statistics website.

## Tech Stack
- **Python** — data collection (web scraping) and preprocessing
- **SQL** — data normalization and structuring
- **Power BI** — 6-page interactive dashboard
- **Excel** — supporting dataset

## Dashboard Pages
1. Overview
2. Land Power
3. **Air Power** — total aircraft, fighters, helicopters, fighter ratio by country, attack forces by region, tankers & transport by country
4. Naval Power
5. Manpower
6. Finance / Energy
